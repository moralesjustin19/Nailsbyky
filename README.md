# 🌸 Site Web de Manucure NailsByKy

Bienvenue sur le dépôt du site web de manucure. Ce site est conçu pour présenter les services de manucure, offrir une galerie en mosaïque, proposer des prestations à la vente et fournir des informations de contact.

## 📌 Structure du Site

Le site comprend les pages suivantes :

- **`index.html`** : Page d'accueil avec une présentation générale.
- **`mosaïque.html`** : Galerie d'images des réalisations de manucure.
- **`vente.html`** : Page dédiée à la vente des prestations et/ou produits.
- **`presentation.html`** : Détails des services proposés et informations de contact.

## 🛠️ Technologies Utilisées

Le site repose sur les technologies suivantes :

- **HTML** : Structure des pages web.
- **CSS** : Mise en page et styles visuels.
- **PHP** : Gestion des interactions dynamiques et des formulaires.
- **SQL** : Stockage et gestion des données (clients, réservations, etc.).
- **Plesk** : Hébergement et gestion du serveur.

## 🚀 Installation et Déploiement

1. **Cloner le dépôt** :
   ```bash
   git clone https://github.com/votre-utilisateur/votre-repo.git
   ```
2. **Déployer sur un serveur Plesk** :
   - Importer les fichiers du site sur Plesk.
   - Configurer une base de données SQL si nécessaire.
   - Vérifier la configuration PHP.
3. **Accéder au site** via l'URL de votre domaine.
